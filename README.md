SDL is needed for this simulator. The include and lib folders of the SDL library, that are necessary for compiling, are included in the repository. Download the repository and run the makefile (in case you have GNU g++ installed) to compile the file and run the program.

The program is a so-called n-body-simulator. When it is runned, a black screen will appear. With the arrow keys on the keyboard, the inital speed can be increased in x and y directions. The selected speeds will be monitored on the terminal. 
With the minus and plus keys on the numpad, the mass of the body can be changed. The mass will also appear on the terminal. 

When initial speeds and mass are selected, press somewhere on the black screen to set the body's initial position. After all desired bodies are ready, press the space key to run the simulator and enjoy the motion!
